# Claude Monitor

Monitor tool for Claude Code CLI instances.

## Features

- Monitor multiple Claude Code CLI instances
- Real-time status updates
- Terminal UI (TUI) and Web UI

## Installation

```bash
pnpm install
```

## Usage

```bash
pnpm dev
```

## Development

```bash
# Install dependencies
pnpm install

# Run in development mode
pnpm dev

# Build
pnpm build

# Run tests
pnpm test

# Type check
pnpm typecheck
```
